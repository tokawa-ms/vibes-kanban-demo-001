# カンバンタスク管理アプリケーション

## 概要
カンバン方式のタスク管理アプリケーションです。直感的なUI/UXでタスクを効率的に管理できます。

## 機能一覧

### ✅ 実装済み機能

#### 基本機能
- **タスク管理**: タスクの作成、編集、削除
- **ステータス管理**: 3つのステータス（未着手、進行中、完了）
- **ドラッグ&ドロップ**: タスクのステータス変更
- **データ永続化**: ローカルストレージによるデータ保存

#### タスク情報
- **基本情報**: タイトル、説明、作成日時、更新日時
- **優先度設定**: 高・中・低の3段階
- **優先度表示**: 色分けによる視覚的な識別

#### 検索・フィルタリング・ソート
- **検索機能**: タイトルと説明の全文検索（ハイライト表示）
- **ステータスフィルタ**: ステータス別の表示切り替え
- **ソート機能**: 作成日時、更新日時、優先度順

#### アーカイブ機能
- **タスクアーカイブ**: 完了タスクのアーカイブ
- **復元機能**: アーカイブされたタスクの復元
- **アーカイブ表示**: 折りたたみ式のアーカイブセクション

#### UI/UX
- **レスポンシブデザイン**: PC、タブレット、スマートフォン対応
- **アニメーション**: タスク完了時のアニメーション効果
- **モーダルダイアログ**: タスク作成・編集用のモーダル
- **カウント表示**: 各ステータスのタスク数表示

#### アクセシビリティ
- **キーボードショートカット**: Ctrl/Cmd+N（新規タスク）、Escape（モーダル閉じる）
- **フォーカス管理**: 適切なフォーカス遷移
- **カラーアクセシビリティ**: 優先度に応じた色分け

## 技術スタック

### フロントエンド
- **HTML5**: セマンティックなマークアップ
- **CSS3**: カスタムスタイルとアニメーション
- **Tailwind CSS**: ユーティリティファーストCSS（CDN版）
- **JavaScript ES6+**: モダンなJavaScript実装

### データ保存
- **LocalStorage**: ブラウザのローカルストレージAPI

## データ構造

### タスクオブジェクト
```javascript
{
  id: string,           // 一意のID
  title: string,        // タスクタイトル
  description: string,  // タスク説明
  status: string,       // 'todo' | 'progress' | 'done'
  priority: string,     // 'high' | 'medium' | 'low'
  createdAt: string,    // ISO8601形式の作成日時
  updatedAt: string,    // ISO8601形式の更新日時
  archivedAt?: string   // アーカイブ日時（アーカイブ済みの場合）
}
```

## 使用方法

### 基本操作
1. **新しいタスクの作成**: 「新しいタスク」ボタンをクリック
2. **タスクの編集**: タスクカードの編集ボタンをクリック
3. **タスクの削除**: タスクカードの削除ボタンをクリック
4. **ステータス変更**: ドラッグ&ドロップでタスクを移動

### 検索・フィルタ
1. **検索**: 検索ボックスにキーワードを入力
2. **ステータスフィルタ**: ドロップダウンからステータスを選択
3. **ソート**: ソートドロップダウンから並び順を選択

### アーカイブ
1. **アーカイブ**: 完了タスクのアーカイブボタンをクリック
2. **復元**: アーカイブセクションの復元ボタンをクリック
