# サウンドエフェクトとビジュアルエフェクト機能

カンバンボードにタスクを移動した際のサウンドエフェクトとビジュアルエフェクトを実装しました。

## 実装された機能

### 進行中への移動エフェクト（モチベーション向上）

**サウンドエフェクト:**
- Web Audio APIを使用した上昇音階のトーン
- 440Hz から 880Hz へのスムーズな音程上昇
- やる気を促進する三角波形を使用
- 0.3秒間の再生時間

**ビジュアルエフェクト:**
- 青色のバウンスアニメーション
- タスクカードが上方向にジャンプ
- 青いグローエフェクト
- スケールアップ効果（1.08倍まで拡大）
- 0.5秒間のアニメーション

### 完了への移動エフェクト（達成感）

**サウンドエフェクト:**
- メジャーコード（C、E、G）を使った祝福サウンド
- 各音符を少しずらして豊かな響きを作成
- サイン波を使用したクリアなトーン
- 0.8秒間の長めの再生時間

**ビジュアルエフェクト:**
- 回転とスケールを組み合わせたセレブレーション
- カラフルなグラデーション背景
- パーティクルエフェクト（疑似粒子）
- 1.2秒間の長いアニメーション
- より派手で達成感を演出

## 技術的詳細

### Web Audio API の使用
- ブラウザの Web Audio API を活用
- ユーザーインタラクション後に音声コンテキストを適切に管理
- 音声がサポートされていない環境でも正常に動作

### CSS アニメーション
- `@keyframes` を使用したスムーズなアニメーション
- `transform` プロパティでのパフォーマンス最適化
- `box-shadow` によるグローエフェクト
- レスポンシブ対応

### 実装場所
- **JavaScript**: `src/js/script.js` の `updateTaskStatus` メソッド
- **CSS**: `src/css/styles.css` の `.task-progress` と `.task-celebrate` クラス
- **音声生成**: `playProgressSound()` と `playCompletionSound()` メソッド

## 使用方法

1. タスクをドラッグ＆ドロップで「進行中」カラムに移動
   → モチベーション向上のサウンドとビジュアルエフェクトが再生

2. タスクをドラッグ＆ドロップで「完了」カラムに移動
   → 達成感のある派手なサウンドとビジュアルエフェクトが再生

## ブラウザ対応

- Chrome/Edge: 完全対応
- Firefox: 完全対応
- Safari: Web Audio API 対応（iOS 11以降）
- モバイルブラウザ: 音声は初回タップ後に有効化
